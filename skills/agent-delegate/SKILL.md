# Agent Delegation

- Mentioning delegation does not justify it.
- Delegate only bounded, isolatable, independently checkable work when compact return saves more main-context cost than setup and transferred context.
- Keep work in main when it needs existing context, authority, synthesis, user decisions, ambiguity resolution, or risky action.
- Contract: goal, scoped inputs/exclusions, expected compact evidence/result, completion or failure condition. Send needed context only.
- Describe needed capability and output, not worker name.
- If to-do list exists and has independent tasks: parallelize.
- If single task will be delegated, and itself can be parallelized, consider option.
- Parallelize independent contracts only. Main integrates conclusion, evidence, blockers; discard exploration detail.
- Ordinary failure or low value: continue main or retry narrower/new evidence. Never bypass safety or authority refusal.
