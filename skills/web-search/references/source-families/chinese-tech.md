# chinese-tech

Use for Chinese-market hardware, Chinese-only docs, Chinese-dominant software communities.

## Prefer

1. Vendor datasheet/manual PDF
2. Original technical post with schematic, code, dates, discussion
3. Verified expert answer

## Queries

- Run English and Chinese variants
- Vendor Chinese name + model
- `site:csdn.net <term>` or source-specific equivalent
- Preserve useful Chinese terms verbatim:
  - `报错` `解决方案` `教程` `原理` `实现` `踩坑` `使用`
  - `文档` `资料` `模块` `芯片` `电路`

## Extract / flag

- Translate key fact; retain Chinese quote, PDF page, section, pinout, register, timing value
- Flag repost farms, auto-translation, inaccessible vendor PDF, model-name mismatch
