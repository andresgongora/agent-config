# general-web

Use for blogs, news, product comparisons, adoption, practice, community sentiment.

## Prefer

1. Official docs, changelogs, company posts
2. Engineering blogs from operators at scale
3. Dated, concrete independent articles
4. HN/Reddit only for experience or leads

## Queries

- `<topic> best practices <year>`
- `<library A> vs <library B>`
- `<technology> at scale`
- `site:news.ycombinator.com <topic>`

## Reject / flag

- SEO listicles, copied docs, generated filler
- vendor marketing without independent check
- undated or stale practice advice
- sentiment presented as fact
