# academic-papers

Use for original papers, algorithm origins, formal specifications, benchmarks, citations.

## Prefer

1. Original paper and canonical DOI/arXiv link
2. Peer-reviewed venue or survey paper
3. Later citation/review identifying dispute or extension

## Queries

- `"<exact title>"`
- `<author> <year> <concept>`
- DOI lookup
- `<concept> <year range>`

## Extract / flag

- title, authors, year, venue, canonical link, key claim
- flag preprint status, version drift, citation count as proxy only, paywall
