# stackoverflow

Use for programming Q&A, API usage, syntax, idioms, standard-library behavior.

## Prefer

1. Official docs when available
2. Accepted/high-vote answer with version match
3. Recent correction in answers or comments

## Queries

- `site:stackoverflow.com <language> <verb> <object>`
- `"<exact error>"`
- `[<tag>] <question>`
- `<question> after:<year>`

## Reject / flag

- deprecated API answer
- accepted answer contradicted by newer correction
- low-vote unsupported answer
