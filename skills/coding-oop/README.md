# coding-oop skill

Object-oriented design child skill for composition, inheritance, and interfaces.

## Design intent

Minimal family child. Holds two durable design signals; does not invent language or framework rules.

## Trigger summary

Object-oriented design, inheritance, class hierarchies, interfaces, or composition.

## Maintainer constraints

- Keep source principles concrete and cross-language.
- Add rules only after repeated object-oriented design work exposes a durable gap.
- Keep language-specific syntax and framework conventions out.
