# ASD-STE100 for Directives

Adapted, simplified guidance. Not formal ASD-STE100 compliance. Use only for directive portions: steps, commands, warnings, and actionable items.

## Core rules

- Use one accurate name for one thing. Change name only for a real distinction.
- Prefer short familiar word when equally exact. Keep necessary technical term.
- Give each key word one meaning within local context.
- Use active voice unless actor is unknown, irrelevant, or passive form is clearer.
- Use direct verb for action: `analyze the log`, not `perform an analysis of the log`.
- State uncertainty once and specifically. Remove empty lead-ins and stacked hedges.
- Replace marketing adjectives with observable behavior, scope, constraint, or result.

## Steps and commands

- Give each numbered item one required action. Use a separate sentence for each instruction; start action sentence with imperative verb.
- Put condition before command: `If the service is running, stop it.`
- Split actions that reader must perform separately. Do not stitch them together with commas, dashes, or clauses.
- State warning or precondition before action. State expected result when reader needs it to verify progress.
- Keep rationale, evidence, caveats, and wider explanation outside the directive. Write them under main prose rules.

## Check

- Each term identifies one thing.
- Each step states condition, action, and needed result or consequence.
- Reader can follow order without inferring a missing action.
